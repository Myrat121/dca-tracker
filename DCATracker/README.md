# DCA Tracker (Android)

Your BTC/ETH DCA ladder tracker as an Android app.

- Live Bybit perpetual prices every 30 seconds while open
- Background checks about every 15 minutes, even when the app is closed
- Phone notifications (and optional Telegram) for: near a buy level, buy level hit, near sell target, sell target hit
- Edit ladders, tick filled steps, see average entry, P/L, target profit and total investment

## Getting the APK
Every time files are uploaded to this repository, GitHub builds the app automatically
(**Actions** tab). When the build shows a green tick, the APK appears under **Releases**
as `DCA-Tracker.apk`.
